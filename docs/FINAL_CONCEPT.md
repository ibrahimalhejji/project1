# التصور النهائي لمنصة CMChub.net
## Smart Conference Management · الإدارة الذكية للمؤتمرات

**الإصدار:** 1.0 · **الحالة:** جاهز للنشر (Phase 1 مكتملة) · **المستودع:** الفرع `claude/restore-conference-platform-c1tzi7`

---

## 1. الرؤية

CMChub.net منصة عربية/إنجليزية تتيح لأي جهة (جامعة، جمعية علمية، شركة تنظيم فعاليات) أن **تنشئ مؤتمرها وتديره بالكامل بنفسها**: الموقع العام للمؤتمر، البرنامج، المتحدثون، الرعاة، التسجيل الإلكتروني، واستقبال الملخصات البحثية وتحكيمها، مع دعم فني من فريق المنصة.

تستعيد النسخة الجديدة فكرة الموقع الأصلي (2015) الذي قدّم خيارَي **«إنشاء مؤتمر»** و**«الدعم الفني»** كمدخلين رئيسيين، وتعيد بناءهما بتقنيات حديثة وهوية CMChub.net (الشعار الأزرق مع النقاط الملونة، والسطر الذهبي Smart Conference Management).

## 2. الجمهور والأدوار

| الدور | من هو | ماذا يستطيع |
| --- | --- | --- |
| **الزائر / المشارك** | باحث، مهتم، حاضر | تصفح المؤتمرات والبرنامج والمتحدثين، التسجيل، تقديم ملخص، التواصل، طلب دعم |
| **المنظّم (Organizer)** | الجهة المنظمة للمؤتمر | يفتح حساباً ذاتياً، ينشئ مؤتمراته ويدير كل تفاصيلها، يرى تسجيلاته وملخصاته فقط |
| **المشرف (Admin)** | فريق CMChub.net | كل صلاحيات المنظم على جميع المؤتمرات + إدارة المستخدمين والأدوار + صندوق الرسائل والدعم |

قاعدة الصلاحيات: كل مؤتمر له **مالك** (owner). المنظّم لا يرى ولا يعدّل إلا ما يملكه؛ المشرف يرى الكل ويستطيع نقل ملكية مؤتمر إلى منظّم آخر.

## 3. الوحدات (Modules)

### 3.1 الموقع العام
| الصفحة | المسار | المحتوى |
| --- | --- | --- |
| الرئيسية | `/ar` · `/en` | الشعار والرسالة، إحصاءات حية (مؤتمرات، متحدثون، تسجيلات)، المؤتمرات القادمة، المزايا، دعوة «أنشئ مؤتمرك» |
| المؤتمرات | `/conferences` | القادمة والسابقة (المنشورة فقط) |
| صفحة المؤتمر | `/conferences/[slug]` | الغلاف، التاريخ والمكان، النبذة، البرنامج حسب الأيام والمسارات والقاعات، المتحدثون، الرعاة حسب الفئة، بطاقة التسجيل (السعر، السعة المتبقية)، بطاقة الملخصات (الموعد النهائي) |
| التسجيل | `/conferences/[slug]/register` | أنواع التذاكر (عادية، طالب، متحدث، VIP)، منع التكرار، إغلاق تلقائي عند اكتمال السعة أو انتهاء المؤتمر، رقم مرجعي REG-XXXXXX |
| تقديم ملخص | `/conferences/[slug]/submit` | عنوان، مؤلفون، جهة، محور، كلمات مفتاحية، نص 100–3000 حرف، رقم مرجعي ABS-XXXXXX |
| المتحدثون | `/speakers` | كل متحدثي المؤتمرات المنشورة |
| عن المنصة | `/about` | الرسالة والمزايا |
| الدعم الفني | `/support` | أسئلة شائعة + نموذج دعم (يصل إلى صندوق المشرف بوسم «دعم فني») |
| اتصل بنا | `/contact` | نموذج تواصل عام |
| أنشئ مؤتمرك | `/signup` | إنشاء حساب منظّم بثلاث خطوات ثم الانتقال مباشرة إلى «مؤتمر جديد» |
| الدخول | `/login` | للمنظمين والمشرفين |

### 3.2 لوحة التحكم (`/admin`)
| القسم | الوظائف |
| --- | --- |
| نظرة عامة | أعداد المؤتمرات والمنشور منها، التسجيلات، الملخصات بانتظار التحكيم، الرسائل غير المقروءة (للمشرف)، أحدث التسجيلات والملخصات |
| المؤتمرات | إنشاء / تعديل (الأساسيات، المحتوى بلغتين، التاريخ والمكان، إعدادات التسجيل والملخصات) / نشر / إلغاء نشر / أرشفة / حذف / تعيين المالك (مشرف) |
| الجلسات والمسارات | مسارات ملونة، جلسات متعددة الأيام بأنواع (كلمة رئيسية، محاضرة، ورشة، حوارية، استراحة)، قاعة، ترتيب، ربط عدة متحدثين |
| المتحدثون | ملف ثنائي اللغة، صورة، جهة، روابط، وسم «متحدث رئيسي» |
| الرعاة | فئات (بلاتيني، ذهبي، فضي، برونزي، شريك، إعلامي)، شعار، رابط |
| التسجيلات | جدول كامل، تغيير الحالة (قيد الانتظار، مؤكد، ملغي، حضر)، حذف، **تصدير CSV** متوافق مع Excel والعربية |
| الملخصات | قراءة النص كاملاً، الحالة (مُقدَّم، قيد التحكيم، مقبول، مرفوض)، ملاحظات المحكّم |
| الرسائل (مشرف) | التواصل والدعم الفني مع وسم الفئة، تحديد كمقروء، حذف |
| المستخدمون (مشرف) | قائمة الحسابات، تغيير الدور، عدد مؤتمرات كل منظّم، حذف |

## 4. رحلات المستخدم الرئيسية

1. **منظّم جديد**: الرئيسية ← «أنشئ مؤتمرك» ← حساب (اسم، جهة، بريد، كلمة مرور) ← نموذج مؤتمر جديد ← يحفظ كمسودة ← يضيف المسارات والجلسات والمتحدثين والرعاة ← يفعّل التسجيل والملخصات ← **نشر** ← الرابط العام `cmchub.net/ar/conferences/<slug>`.
2. **مشارك**: صفحة المؤتمر ← «سجّل الآن» ← بياناته ونوع التذكرة ← رقم مرجعي ← المنظّم يؤكد من لوحة التحكم ويصدّر القائمة CSV.
3. **باحث**: صفحة المؤتمر ← «قدّم ملخصاً» ← النموذج ← رقم مرجعي ← اللجنة تحكّم من لوحة التحكم وتدوّن الملاحظات.
4. **طلب دعم**: الدعم الفني ← الأسئلة الشائعة أو النموذج ← يصل إلى صندوق المشرف بوسم «دعم فني».

## 5. نموذج البيانات

```
users ──< conferences (owner_id) ──< tracks
                       │           ──< sessions >──< session_speakers >──< speakers
                       │           ──< sponsors
                       │           ──< registrations
                       │           ──< abstracts
messages (category: contact | support)
```
- كل النصوص الظاهرة للجمهور ثنائية اللغة (`*_ar` / `*_en`) مع تراجع تلقائي إلى اللغة المتوفرة.
- قاعدة البيانات SQLite عبر libsql (ملف واحد يسهل نسخه احتياطياً)، ويمكن الانتقال إلى Turso/Postgres دون تغيير الكود.
- المخطط الكامل في `src/db/schema.ts` والترحيلات في `drizzle/`.

## 6. الهوية البصرية

- **الشعار**: الهلال الأزرق متعدد الطبقات مع أربع نقاط (ذهبي، ذهبي، تركوازي، بنفسجي)، مرسوم كـ SVG (`src/components/Logo.tsx`، `src/app/icon.svg`).
- **الشعار النصي**: CMC (أزرق فولاذي) hub (سماوي فاتح) .net (أزرق) + السطر الذهبي.
- **الألوان**: أزرق فولاذي `#3b7fa6`، كحلي `#1f3b5c`، سماوي `#a9d6e3`، ذهبي `#c9a24a`، تركوازي `#2f6f7e`، بنفسجي `#4b3f8f`.
- **الاتجاه**: العربية افتراضياً (RTL) مع تبديل فوري إلى الإنجليزية من أي صفحة.

## 7. البنية التقنية والأمان

| الطبقة | الاختيار |
| --- | --- |
| الواجهة والخادم | Next.js 15 (App Router، Server Actions)، TypeScript، Tailwind CSS v4 |
| قاعدة البيانات | SQLite/libsql + Drizzle ORM، ترحيلات تُطبَّق تلقائياً عند التشغيل |
| المصادقة | جلسات موقّعة HMAC-SHA256 في Cookie آمن (HttpOnly, SameSite, Secure)، كلمات مرور scrypt |
| الصلاحيات | Middleware يحمي `/admin`، وكل إجراء خادمي يتحقق من الدور ومن ملكية المؤتمر |
| التحقق من المدخلات | على الخادم لكل نموذج، حدود أطوال، منع التكرار، تحكم بالسعة والمواعيد |
| النشر | حزمة standalone (Node 20+)، Docker، PM2، أو Vercel/Railway مع Turso |

## 8. ما أُنجز وما يلي

**المرحلة 1 (مكتملة ومختبرة):** كل ما سبق، مع اختبار متصفح آلي يغطي التسجيل والملخصات والتحكيم وإنشاء المؤتمرات والجلسات والمتحدثين والرعاة والصلاحيات وتبديل اللغة.

**المرحلة 2 (مقترحة):**
- إشعارات بريدية (تأكيد التسجيل، نتيجة التحكيم، إعادة تعيين كلمة المرور) عبر SMTP أو Resend.
- بوابة دفع للتذاكر (Moyasar / Stripe / PayPal) مع فواتير.
- لجان المؤتمر، الأخبار والإعلانات، معرض الصور، ملفات PDF للملخصات.
- شهادات حضور PDF ورموز QR للتحقق عند الدخول.
- صفحة مؤتمر بنطاق فرعي أو نطاق خاص لكل منظّم.

**المرحلة 3:** تطبيق جوال (PWA)، تحليلات، تكامل Zoom للجلسات الافتراضية.
