# محرك إنشاء المقالات

محرك مبسّط للغاية: تدخل **عنوان المقال** و**الشريحة المستهدفة** و**عدد الكلمات**، فيكتب وكيلُ كتابة المقالَ بـ**مهارة** محددة، ثم يراجعه **وكلاء المراجعة** ويعاد تعديله حتى يُعتمد.

```
المدخلات ──▶ وكيل الكتابة ──▶ مسودة ──▶ وكلاء المراجعة ──▶ معتمد؟ ──نعم──▶ output/
                  ▲                                            │
                  └──────────── ملاحظات التعديل ◀───── لا ──────┘
```

## التركيب

| المسار | ما فيه |
|---|---|
| `engine.py` | المحرك كله (ملف واحد) |
| `skills/*.md` | المهارات: أسلوب الكتابة وبنيتها (`general`، `seo`) |
| `agents/writers/*.md` | وكلاء الكتابة: من يستلم الطلب ويكتب (`journalist`، `academic`) |
| `agents/reviewers/*.md` | وكلاء المراجعة: من يراجع ويعتمد (`language`، `content`، `audience`) |
| `output/` | المقالات النهائية وتقارير المراجعة |

كل مهارة وكل وكيل هو **ملف Markdown واحد** يصف الدور وقواعده. لإضافة وكيل أو مهارة جديدة أنشئ ملفًا في المجلد المناسب، ويصبح متاحًا فورًا باسم الملف.

## التثبيت

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
```

## التشغيل

```bash
# تفاعلي: يسألك عن العنوان والشريحة
python engine.py

# مباشر
python engine.py --title "كيف تبدأ الاستثمار بمبلغ صغير" \
                 --audience "شباب في أول وظيفة" \
                 --words 900

# اختيار المهارة والكاتب والمراجعين
python engine.py --title "ما هو الذكاء الاصطناعي التوليدي" \
                 --audience "مديرون غير تقنيين" \
                 --words 1200 \
                 --skill seo \
                 --writer academic \
                 --reviewers content audience \
                 --rounds 3

# عرض المتاح
python engine.py --list
```

## المدخلات

| الخيار | المعنى | الافتراضي |
|---|---|---|
| `--title` | عنوان المقال | يُسأل تفاعليًا |
| `--audience` | الشريحة المستهدفة | يُسأل تفاعليًا |
| `--words` | عدد الكلمات | 800 |
| `--skill` | المهارة التي يُكتب بها المقال | `general` |
| `--writer` | وكيل الكتابة الذي يستلم الطلب | `journalist` |
| `--reviewers` | وكلاء المراجعة (واحد أو أكثر) | الجميع |
| `--rounds` | أقصى عدد جولات المراجعة والتعديل | 2 |
| `--language` | لغة المقال | العربية |
| `--model` | نموذج Claude | `claude-opus-5-5` |

## كيف يعمل

1. يحمّل المحرك ملف المهارة وملف الكاتب وملفات المراجعين.
2. يكتب الكاتب المسودة الأولى بحسب المدخلات والمهارة.
3. يقيّم كل مراجع المسودة ويعيد حكمًا منظّمًا: `approved` و`score` من 10 و`notes`.
4. إن اعتمد الجميع يُحفظ المقال. وإلا تُجمع ملاحظات غير المعتمدين وتُرسل إلى الكاتب ليعدّل، ثم تبدأ جولة جديدة.
5. عند انتهاء الجولات يُحفظ آخر إصدار مع التقرير في كل الأحوال.

## المخرجات

- `output/<العنوان>.md` المقال النهائي بصيغة Markdown.
- `output/<العنوان>.review.md` تقرير المراجعة: درجات وملاحظات كل مراجع في كل جولة.

## ملاحظات

- المحرك يفعّل الاحتياط الخادمي (`fallbacks: default`) فإذا رفض النموذج طلبًا لأسباب الأمان أُعيد تلقائيًا على نموذج بديل.
- الطلبات تُبثّ تدفقيًا لتجنب انقطاع المقالات الطويلة.
