# project1

أربعة محرّكات مبسّطة مبنية على Claude، كل واحد في مجلده المستقل بملف بايثون واحد وملفات Markdown قابلة للتوسيع:

| المجلد | المحرك | المدخلات | المخرجات |
|---|---|---|---|
| [`article-engine/`](article-engine/) | إنشاء المقالات | عنوان، شريحة مستهدفة، عدد كلمات، مهارة، كاتب، مراجعون | مقال معتمد + تقرير مراجعة |
| [`image-to-prompt/`](image-to-prompt/) | تحويل الصور إلى برومبتات | صورة، نمط إخراج (18 نمطًا)، محرك صور مستهدف | برومبت جاهز للنسخ + وصف عربي |
| [`seo-engine/`](seo-engine/) | دراسة SEO مصغّرة | الدومين فقط | كلمات مفتاحية، عنوان ووصف، فحص تقني، إصلاحات سريعة |
| [`quotes-engine/`](quotes-engine/) | الاقتباسات العربية | كتاب أو مقالة أو عنوان، العدد، النمط | 50 اقتباسًا مشكولًا مع تحقّق حرفي، Markdown + JSON |

كل مجلد يحوي `README.md` بدليل التشغيل الكامل. المتطلب الوحيد: `pip install anthropic` ومفتاح `ANTHROPIC_API_KEY`.
