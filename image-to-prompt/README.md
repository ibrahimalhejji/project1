# محرك تحويل الصور إلى برومبتات

محرك مبسّط للغاية: تعطيه **صورة** وتختار **كيف تريد أن تخرج** (إعلان، موك أب، سينمائي، ...) و**أي محرك صور** ستستعمل، فيحلّل الصورة ويكتب لك برومبتًا جاهزًا للنسخ.

```
صورة ──▶ تحليل بصري ──▶ نمط الإخراج ──▶ صيغة المحرك المستهدف ──▶ برومبت جاهز + وصف عربي
```

## التركيب

| المسار | ما فيه |
|---|---|
| `engine.py` | المحرك كله (ملف واحد) |
| `styles/*.md` | أنماط الإخراج: كيف تريد أن تخرج الصورة (18 نمطًا) |
| `targets/*.md` | صيغة البرومبت بحسب محرك الصور (5 محركات) |
| `output/` | البرومبتات المحفوظة بصيغة Markdown |

كل نمط وكل محرك هو **ملف Markdown واحد**. لإضافة نمط جديد أنشئ ملفًا في `styles/` ويصبح متاحًا فورًا باسمه.

## أنماط الإخراج

| النمط | الفكرة |
|---|---|
| `faithful` | إعادة إنتاج مطابقة للصورة كما هي (الافتراضي) |
| `mockup` | موك أب: المحتوى مركّب على منتج أو لافتة أو شاشة |
| `ad` | إعلان تجاري: بوستر أو لوحة إعلانية مع مساحة للنص |
| `cinematic` | لقطة سينمائية عريضة بتدرّج لوني درامي |
| `product` | تصوير منتج استوديو بخلفية نظيفة |
| `3d` | رندر ثلاثي الأبعاد واقعي أو ستايلايزد |
| `anime` | أسلوب الأنمي الياباني |
| `painting` | لوحة زيتية أو ألوان مائية |
| `logo` | شعار أو أيقونة مسطحة بسيطة |
| `social` | منشور سوشيال ميديا بمساحة للعنوان |
| `fantasy` | عالم خيالي ملحمي |
| `vintage` | صورة قديمة بحبيبات فيلم وألوان باهتة |
| `isometric` | ديوراما أيزومترية مصغّرة |
| `pixel` | بكسل آرت من ألعاب الفيديو القديمة |
| `sketch` | رسم بالقلم الرصاص أو الحبر |
| `neon` | نيون سايبربانك في مدينة ليلية |
| `kids` | رسمة كتاب قصص للأطفال |
| `luxury` | طابع فاخر بمستوى مجلة راقية |

## المحركات المستهدفة

`generic` (يعمل في أغلب المحركات، الافتراضي) · `midjourney` · `dalle` · `stable-diffusion` · `flux`

## التثبيت

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
```

## التشغيل

```bash
# برومبت مطابق للصورة
python engine.py photo.jpg

# الصورة كإعلان بصيغة Midjourney مع 3 بدائل
python engine.py photo.jpg --style ad --target midjourney --variations 3

# الصورة بكل الأنماط الـ18 دفعة واحدة
python engine.py photo.jpg --style all

# من رابط، مع ملاحظة حرة
python engine.py https://example.com/photo.png --style mockup --notes "خلفية بيضاء، بلا نص"

# عدة صور معًا
python engine.py a.jpg b.png c.webp --style product --target stable-diffusion

# عرض المتاح
python engine.py --list
```

## المدخلات

| الخيار | المعنى | الافتراضي |
|---|---|---|
| `images` | مسار صورة أو رابطها (واحدة أو أكثر) | مطلوب |
| `--style` | نمط الإخراج، أو `all` لكل الأنماط | `faithful` |
| `--target` | محرك الصور المستهدف | `generic` |
| `--variations` | عدد البدائل لكل صورة (1 إلى 5) | 1 |
| `--notes` | ملاحظات حرة تُضاف للطلب ولها الأولوية | لا شيء |
| `--model` | نموذج Claude | `claude-opus-5-5` |

الصيغ المدعومة: JPG، PNG، GIF، WebP، بحد أقصى 5 ميغابايت للصورة.

## المخرجات

لكل صورة ونمط ملف `output/<اسم الصورة>.<النمط>.<المحرك>.md` يحوي:

- تحليلًا عربيًا للصورة (الموضوع، التكوين، الإضاءة، الألوان، المزاج).
- البرومبت الإنجليزي جاهزًا للنسخ داخل كتلة كود.
- Negative prompt إن كان المحرك يستعمله.
- نسبة الأبعاد المقترحة وملاحظة عربية بما تغيّر عن الأصل.

البرومبتات تُطبع أيضًا في الطرفية مباشرة للنسخ السريع.

## ملاحظات

- البرومبت بالإنجليزية لأن محركات الصور تفهمها أفضل؛ التحليل والملاحظات بالعربية.
- المحرك لا يذكر أسماء أشخاص حقيقيين أو علامات تجارية؛ يصف الملامح والأسلوب بدلًا منها.
- يفعّل الاحتياط الخادمي (`fallbacks: default`) فإذا رفض النموذج صورة أُعيد الطلب تلقائيًا على نموذج بديل.
