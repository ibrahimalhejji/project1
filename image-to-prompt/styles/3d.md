# نمط: رندر ثلاثي الأبعاد (3d)

الهدف: الصورة كرندر ثلاثي الأبعاد عالي الجودة.
- حدّد الطابع: واقعي (Octane / Unreal) أو ستايلايزد (Pixar-like، أسطح ناعمة ملوّنة).
- إضاءة عامة (global illumination)، خامات واضحة (معدن، زجاج، بلاستيك مطفي، قماش)، subsurface scattering للأشياء العضوية.
- الكلمات المفتاحية المفيدة: 3D render, octane render, unreal engine, global illumination, ray tracing, soft studio lighting, high detail, 8k.
- للطابع الكرتوني أضف: stylized 3D, smooth shading, pastel colors, cute proportions.
