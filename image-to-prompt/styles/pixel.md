# نمط: بكسل آرت (pixel)

الهدف: الصورة بأسلوب ألعاب الفيديو القديمة.
- دقة منخفضة واضحة (16-bit أو 32-bit)، لوحة ألوان محدودة، حواف مسنّنة مقصودة بلا تنعيم.
- بسّط الأشكال إلى كتل واضحة مع إبقاء الموضوع قابلًا للتمييز فورًا.
- يمكن إضافة عناصر واجهة لعبة قديمة إن ناسب المشهد (بلا نص فعلي).
- الكلمات المفتاحية المفيدة: pixel art, 16-bit, retro game sprite, limited palette, crisp pixels, dithering, side-scroller scene.
