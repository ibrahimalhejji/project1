# نمط: رسم تخطيطي (sketch)

الهدف: الصورة كرسم يدوي بالقلم الرصاص أو الحبر.
- خطوط واثقة، تظليل بالتهشير (hatching / cross-hatching)، ورق بملمس خفيف، بلا تلوين أو بلمسة لون واحدة.
- حدّد الطابع: رسم معماري دقيق، اسكتش دفتر سريع، رسم تشريحي تفصيلي.
- اترك بعض المناطق غير مكتملة عمدًا لتبدو حية.
- الكلمات المفتاحية المفيدة: pencil sketch, ink drawing, hatching, sketchbook, hand-drawn, line art, monochrome, paper texture.
