# نمط: موك أب (mockup)

الهدف: عرض محتوى الصورة كتصميم مطبوع أو مركّب على منتج حقيقي (عبوة، تيشيرت، لوحة، شاشة هاتف، كوب، لافتة متجر).
- اختر حاملًا مناسبًا لطبيعة الصورة: شعار ← لافتة أو بطاقة عمل، منظر ← لوحة جدارية، منتج ← عبوة أو رف متجر.
- صِف المشهد الواقعي للحامل: سطح، إضاءة استوديو ناعمة، ظلال طبيعية، عمق ميداني خفيف.
- الكلمات المفتاحية المفيدة: realistic mockup, product presentation, studio lighting, soft shadows, photorealistic, clean background.
- الصورة الأصلية تبقى هي المحتوى المعروض، لا تغيّر جوهرها.
