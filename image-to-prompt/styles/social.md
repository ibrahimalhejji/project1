# نمط: منشور سوشيال ميديا (social)

الهدف: الصورة كمنشور جذاب لإنستغرام أو تيك توك أو لينكدإن.
- نسبة أبعاد مربعة (1:1) أو عمودية (4:5 / 9:16) بحسب المنصة الأنسب للموضوع.
- ألوان جريئة متناسقة، موضوع واضح يوقف التمرير في أول ثانية، تكوين بسيط.
- مساحة فارغة واضحة في الأعلى أو الأسفل لعنوان قصير (لا تكتب النص نفسه).
- الكلمات المفتاحية المفيدة: social media post, eye-catching, bold colors, trendy, clean composition, copy space, lifestyle photography.
