# محرك SEO مصغّر

محرك مبسّط للغاية: **مدخل واحد فقط هو الدومين**، فيجلب الصفحة الرئيسية ويدرسها دراسة مصغّرة ويقدّم الكلمات المفتاحية وتوصيات SEO لتحسين الوصول إلى الموقع من محركات البحث.

```
الدومين ──▶ جلب الصفحة الرئيسية + robots.txt ──▶ فحص تقني سريع (14 نقطة) ──▶ تحليل بالنموذج ──▶ تقرير
```

## التركيب

| المسار | ما فيه |
|---|---|
| `engine.py` | المحرك كله: الجلب، الفحص، التحليل، التقرير |
| `web.py` | شريط واحد في المتصفح (اختياري، بلا حزم إضافية) |
| `output/` | التقارير المحفوظة بصيغة Markdown |

## التثبيت

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
```

## التشغيل

```bash
# من سطر الأوامر
python engine.py example.com

# تفاعلي: يسألك عن الدومين
python engine.py

# شريط في المتصفح على http://localhost:8000
python web.py
```

## ما يقدّمه التقرير

1. **عن الموقع**: ما الذي يقدّمه ولمن، في سطور.
2. **الكلمات المفتاحية الرئيسية**: 5 إلى 8 كلمات مع نية البحث وسبب الاختيار.
3. **كلمات ثانوية**: 10 إلى 15 كلمة داعمة.
4. **عبارات طويلة وأسئلة**: 8 إلى 12 عبارة يكتبها الناس فعلًا في البحث.
5. **عنوان ووصف مقترحان**: Title بحد 60 حرفًا وMeta description بحد 155 حرفًا.
6. **الفحص التقني السريع**: 14 نقطة محسوبة محليًا: HTTPS، العنوان والوصف وأطوالهما، H1 واحد، lang، canonical، viewport، alt للصور، noindex، robots.txt، sitemap، كفاية المحتوى.
7. **إصلاحات سريعة**: 5 إلى 8 إصلاحات مرتبة بالأولوية وقابلة للتنفيذ اليوم.
8. **أفكار محتوى**: 5 عناوين مقالات تستهدف الكلمات المقترحة. يمكن تمريرها مباشرة إلى محرك المقالات في `../article-engine/`.

التقرير يُطبع في الطرفية ويُحفظ في `output/<الدومين>.seo.md`.

## حدود الدراسة المصغّرة

- تدرس **الصفحة الرئيسية فقط** مع robots.txt وsitemap، لا الموقع كله.
- الكلمات المفتاحية مقترحة من تحليل المحتوى، **بلا بيانات أحجام بحث أو منافسة**. تحقّق منها في أداة كلمات مفتاحية قبل الاعتماد عليها.
- الكلمات تخرج بلغة الموقع (عربي، إنجليزي، أو مزيج)، والشروح كلها بالعربية.
- المواقع المبنية بالكامل بجافاسكربت قد تعطي محتوى نصيًا قليلًا؛ سيظهر ذلك في الفحص التقني.
