# محرك الاقتباسات العربية

محرك مبسّط: تعطيه **كتابًا أو مقالة** (ملف نصي) أو **مجرد عنوان أو موضوع**، فيشتقّ منه **50 اقتباسًا** عربيًا سليمًا، مشكولًا تشكيلًا كاملًا، مع نسبة صادقة لكل اقتباس.

```
كتاب / مقالة / عنوان ──▶ اشتقاق ──▶ تحقّق حرفي محلي ──▶ مراجعة لغوية + تشكيل ──▶ Markdown + JSON
```

## ما الذي يجعله نقلة في الاقتباسات العربية

| المشكلة الشائعة | ما يفعله المحرك |
|---|---|
| اقتباسات مختلَقة تُنسب إلى مؤلفين لم يقولوها | نوعان صريحان: **حرفي** يتحقق المحرك محليًا من وجوده في النص كما هو، و**مستوحى** يُنسب «مستوحى من» لا قولًا للمؤلف |
| ركاكة وتراكيب مترجمة | معيار عربي إلزامي في التوليد، ثم جولة مراجعة لغوية مستقلة |
| غياب التشكيل أو تشكيل خاطئ | كل اقتباس بنسختَين: مشكول كاملًا وبلا تشكيل، ويُتحقق أن المشكول مطابق للأصل |
| تكرار المعاني | إزالة التكرار محليًا، وتنويع الصيغ البلاغية مطلوب في التوليد |
| مخرجات لا تصلح للمنصات | ملف JSON منظّم مع Markdown للقراءة |

## التركيب

| المسار | ما فيه |
|---|---|
| `engine.py` | المحرك كله (ملف واحد) |
| `output/` | `<الاسم>.quotes.md` للقراءة و`<الاسم>.quotes.json` للمنصات |

## التثبيت

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
```

## التشغيل

```bash
# من كتاب أو مقالة (ملف .txt أو .md): مزيج حرفي ومستوحى
python engine.py book.txt --title "اسم الكتاب" --author "اسم المؤلف"

# من عنوان أو موضوع فقط: اقتباسات مستوحاة
python engine.py "الصبر مفتاح الفرج"

# حرفي فقط من مقالة، 30 اقتباسًا
python engine.py article.md --mode verbatim --count 30

# نبرة محددة وبلا مراجعة (أسرع)
python engine.py book.txt --tone "تحفيزية" --no-review

# تفاعلي
python engine.py
```

## المدخلات

| الخيار | المعنى | الافتراضي |
|---|---|---|
| `source` | مسار ملف نصي (`.txt` / `.md`) أو عنوان/موضوع | يُسأل تفاعليًا |
| `--title` | اسم الكتاب أو المقالة | اسم الملف أو العنوان المدخل |
| `--author` | اسم المؤلف لنسبة الاقتباسات الحرفية إليه | لا شيء |
| `--mode` | `verbatim` حرفي · `derived` مستوحى · `mixed` مزيج · `auto` | `auto`: مزيج مع ملف، مستوحى مع عنوان |
| `--count` | عدد الاقتباسات (1 إلى 100) | 50 |
| `--tone` | نبرة اختيارية (تحفيزية، تأملية، ...) | لا شيء |
| `--no-review` | تخطّي المراجعة اللغوية | المراجعة مفعّلة |
| `--model` | نموذج Claude | `claude-opus-5-5` |

لتحويل كتاب PDF أو Word إلى نص، احفظه أولًا بصيغة `.txt` من البرنامج نفسه.

## شكل المخرجات

في Markdown:

```
**1.** «الصَّبْرُ مِفْتَاحُ كُلِّ بَابٍ مُغْلَقٍ»  
«الصبر مفتاح كل باب مغلق»  
— مستوحى من موضوع «الصبر» · الصبر · مستوحى
```

في JSON لكل اقتباس: `text`، `text_tashkeel`، `theme`، `kind`، `attribution`، `note`.

## ملاحظات

- الكتب الطويلة جدًا (فوق 300 ألف حرف) تُؤخذ منها عيّنات موزّعة، ويُذكر ذلك في أعلى التقرير.
- إذا زعم النموذج أن اقتباسًا حرفي ولم يُعثر عليه في النص، يُسقطه المحرك ويذكر عددها في التقرير بدل تمريرها.
- المحرك لا يختلق آيات أو أحاديث أو أقوالًا لأشخاص حقيقيين.
