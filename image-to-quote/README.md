# محرك «صورة ← اقتباس عن الذكاء الاصطناعي»

محرك صغير: ترفع **صورة**، فينظر فيها ويدرسها، ثم يُنتج **اقتباسًا تحفيزيًا عن الذكاء الاصطناعي من وحيها**، بعربية سليمة ومشكولة.

```
صورة ──▶ انظر (وصف أمين) ──▶ تأمّل (3 جسور إلى الذكاء الاصطناعي) ──▶ صُغ (اقتباس يحمل عنصرًا من الصورة) ──▶ Markdown + JSON
```

## فكرة التصميم

الاقتباس الجيد من صورة لا يأتي من القفز إلى الحكمة مباشرة، بل من ثلاث خطوات يُلزَم بها النموذج في المخرجات نفسها:

| الخطوة | ما يحدث | لماذا |
|---|---|---|
| **انظر** | وصف دقيق لما في الصورة: العناصر، الضوء، الألوان، المزاج | يمنع الاقتباسات العامة التي تصلح لأي صورة |
| **تأمّل** | 3 جسور، كل جسر يربط عنصرًا محددًا من الصورة بفكرة عن الذكاء الاصطناعي | هنا يحدث «التفكير بعمق» قبل الصياغة |
| **صُغ** | اقتباس من 8 إلى 22 كلمة يحمل عنصرًا بصريًا من الصورة، بلا مبالغة ولا تخويف ولا عبارات مبتذلة | يُحسّ أنه خرج من هذه الصورة تحديدًا |

ويُرفق مع كل اقتباس **الرابط بالصورة**: أي عنصر حمله وكيف، حتى تحكم أنت على قوة الصلة.

## التركيب

| المسار | ما فيه |
|---|---|
| `engine.py` | المحرك كله (ملف واحد) |
| `output/` | `<اسم الصورة>.quote.md` للقراءة و`<اسم الصورة>.quote.json` للمنصات |

## التثبيت

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
```

## التشغيل

```bash
# اقتباس واحد من صورة
python engine.py photo.jpg

# ثلاثة اقتباسات بنبرة تأملية
python engine.py photo.jpg --count 3 --tone "تأملية"

# من رابط، مع ملاحظة
python engine.py https://example.com/sunrise.png --notes "لمنشور صباحي لفريق تقني"

# عدة صور معًا
python engine.py a.jpg b.png c.webp

# تفاعلي
python engine.py
```

## المدخلات

| الخيار | المعنى | الافتراضي |
|---|---|---|
| `images` | مسار صورة أو رابطها (واحدة أو أكثر) | يُسأل تفاعليًا |
| `--count` | عدد الاقتباسات لكل صورة (1 إلى 5) | 1 |
| `--tone` | النبرة: تحفيزية، تأملية، حماسية، هادئة... | تحفيزية |
| `--notes` | ملاحظات حرة لها الأولوية | لا شيء |
| `--model` | نموذج Claude | `claude-opus-5-5` |

الصيغ المدعومة: JPG، PNG، GIF، WebP، بحد أقصى 5 ميغابايت للصورة.

## شكل المخرجات

```
## ما في الصورة
طريق جبلي يتصاعد في ضباب الصباح، وضوء خافت يكشف المنعطف التالي فقط...

## الجسور إلى الذكاء الاصطناعي
- الضوء الذي يكشف منعطفًا واحدًا كل مرة يشبه التعلّم خطوة بعد خطوة من البيانات.
- ...

## الاقتباس
**«لَا يَحْتَاجُ الطَّرِيقُ أَنْ يُضَاءَ كُلُّهُ؛ يَكْفِي أَنْ تَرَى الْمُنْعَطَفَ التَّالِي وَتَمْضِيَ»**
«لا يحتاج الطريق أن يضاء كله؛ يكفي أن ترى المنعطف التالي وتمضي»
— من وحي الصورة · التعلّم
الرابط بالصورة: الضوء الخافت الذي يكشف منعطفًا واحدًا فقط من الطريق.
```

في JSON لكل اقتباس: `text`، `text_tashkeel`، `theme`، `image_link_ar`، `attribution`.

## ملاحظات

- الاقتباس من إنشاء المحرك ولا يُنسب إلى أي شخص حقيقي؛ النسبة دائمًا «من وحي الصورة».
- يُتحقق محليًا أن النص المشكول مطابق للنص بلا تشكيل؛ وإلا عُرض النص بلا تشكيل بدل نص مختلف.
- يفعّل الاحتياط الخادمي (`fallbacks: default`) فإذا رفض النموذج صورة أُعيد الطلب تلقائيًا على نموذج بديل.
